# Definitions

Quick look-up for every term, symbol and label in the project. **Short answers only**; for the full explanation with intuition, each entry links to a note in [[_Technical Learning - README|Technical Learning]] or [[_Methodology - README|Methodology]].

| Note | Use it when… |
|---|---|
| [[Glossary A-Z]] | You meet a word or symbol and want its meaning (volatility, CAGR, rolling, drawdown, kurtosis, …) |
| [[Graph and Table Labels]] | You're reading a graph or a CSV table and don't know what an axis, colour or column name (`max_drawdown`, `VR(3)`, `n_sig_robust`, …) means |
| [[Variable Names and Equations]] | You see a name like `top5_vsmom_63d` or `vol_ratio_20d` and want **what it means plus the exact equation**, with a worked example |

**How the three folders fit together:**
- **Definitions**: *what does this word mean?* (one or two lines)
- **Technical Learning**: *how does this concept work?* (intuition + maths)
- **Methodology**: *what did we do in each task, and why?*

New terms are added here as each task introduces them.
